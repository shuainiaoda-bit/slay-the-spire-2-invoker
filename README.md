# Dota 2 · 卡尔 / Invoker 1.1.2

作者：是大帅鸟。《杀戮尖塔2》角色模组。三种元素、十种祈求法术、熔炉精灵与 89 张卡牌。

- [下载最新安装包](https://github.com/shuainiaoda-bit/slay-the-spire-2-invoker/releases/latest)
- [历史版本](https://github.com/shuainiaoda-bit/slay-the-spire-2-invoker/releases)

## 本版更新

适配新版伤害、打牌与回合接口，保留原有卡牌效果、数值和立绘。取消选牌时，卡牌返回手牌且保留能量。

适配游戏 **0.111.1**，附带 **STS2.RitsuLib.Compat.0.111.0 / 0.6.14**。界面和卡牌支持简体中文、英文，随游戏语言切换。

## 安装

退出游戏并备份存档，将安装包 `mods` 中的 `InvokerMod` 和 `STS2-RitsuLib` 文件夹放入游戏目录的 `mods` 文件夹。更新时先备份旧文件，再用包内框架完整替换旧的 `STS2-RitsuLib` 目录，避免混用兼容版本。同时安装卡尔和修补匠时，只保留一份配套框架。启动游戏后选择角色。

建议新开局；旧版战斗中存档迁移与多人联机尚未验证。旧游戏 0.107.1 的安装包仍保留在历史版本中。

下载 Assets 中的 `InvokerMod-1.1.2.zip`。`SHA256SUMS.txt` 用于校验安装包；GitHub 自动生成的 Source code 压缩包是仓库文档。

Dota 素材版权归 Valve；原创角色插画、卡牌插画及封面含 AI 生成图像。本模组为非官方同人作品。包内 RitsuLib 按附带的 MIT 许可证分发。

## English

By 是大帅鸟. Three elements, ten invoked spells, Forge Spirits and 89 cards.

Updated damage, card-play and turn API integration while retaining existing card effects, values and artwork. Cancelling a card selection returns the card to hand and preserves energy.

For **Slay the Spire 2 0.111.1**, with **STS2.RitsuLib.Compat.0.111.0 / 0.6.14** included. Simplified Chinese and English follow the game language.

Exit the game and back up your saves. Copy `InvokerMod` and `STS2-RitsuLib` from the archive's `mods` folder into the game's `mods` directory. Back up and fully replace the old framework folder when updating. Keep one matching framework when using both Invoker and Tinker.

A new run is recommended. Migration of in-combat saves and multiplayer have not been verified. Packages for game 0.107.1 remain available in earlier releases.

Download `InvokerMod-1.1.2.zip` from Assets and use `SHA256SUMS.txt` to check its SHA-256 hash. GitHub's automatic Source code archives contain repository documentation.

Dota assets belong to Valve. Original character art, card illustrations and covers include AI-generated images. This is an unofficial fan mod. The included RitsuLib is distributed under its accompanying MIT license.
